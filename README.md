# Relógio Digital

Projeto de um relógio digital desenvolvido como exercício prático de programação e desenvolvimento web.

## 🎯 Objetivo
Criar uma interface simples para exibição de horário, praticando atualização dinâmica de informações na página.

## 🛠️ Tecnologias
- HTML5
- CSS3
- JavaScript

## 🚀 Como executar
Clone o repositório e abra o arquivo principal HTML em um navegador.
